# LINE見張りの自動起動

## 何をするか
スケジュールされたタスク「LINE見張り」(このユーザーだけ・管理者権限なし・ログオン中だけ動く)が、見張り(`line_agent watch --interval 30`)を非表示で起動する。

- 起動のきっかけ: ログオンの 1 分後と、そのあと 10 分ごとにずっと。
- 動いていれば何もせず終わる(二重起動しない)。落ちていれば、次の 10 分以内に自動で立ち上がる。
- 実体: `scripts/start_watcher.ps1`。venv の `python.exe` を非表示で起動する(`pythonw.exe` は標準出力が無く、`cli.py` が落ちるので使わない)。
- バッテリー駆動でも止めない・時間切れで殺さない・同時実行は無視(IgnoreNew)。

## 完全に止める(自動起動もやめる)
```powershell
Disable-ScheduledTask -TaskName "LINE見張り"     # 戻す: Enable-ScheduledTask
scripts\stop_watcher.ps1                          # 今動いている分も止める
```
完全に消す: `Unregister-ScheduledTask -TaskName "LINE見張り" -Confirm:$false`

## 一度だけ止める
`scripts\stop_watcher.ps1` は STOP ファイルを作って、見張りが止まるまで待つ。
STOP が残っている間は、タスクも見張りを起動しない(autostart.log に `STOP file present, not starting`)。
再開するときは STOP を消す。次の 10 分の巡回で自動で戻る(すぐ戻すなら `Start-ScheduledTask -TaskName "LINE見張り"`)。

## ログとデータの置き場所(重要)
Claude デスクトップアプリ(MSIX 版)の中で動く作業役は、`%LOCALAPPDATA%\line-desktop-agent` への読み書きが
`%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Local\line-desktop-agent` に付け替えられる。
タスクスケジューラ経由のプロセスは付け替えられないので、何もしないと別の line.db / STOP / watcher.log を見てしまう(11-10 に実測)。
そのため `start_watcher.ps1` は、このフォルダが存在すれば `LINE_AGENT_HOME` でそこを指定して起動する。
エージェントの STOP ファイル・line.db とそろう。普通の PowerShell(アプリの外)から見ると、実際のパスは上の長い方。

- `autostart.log`: 起動の記録(起動した・STOP で見送った・失敗した)。動いているだけの巡回は書かない。
- `watcher.log`: 見張り本体の tick 記録。
- タスクの状態: `Get-ScheduledTaskInfo -TaskName "LINE見張り"`(LastTaskResult 0 が正常)。

## 注意
- ログオンしていないと動かない(UIA でデスクトップを読むため)。画面ロック中は未確認。
- Claude アプリのパッケージ名が変わったら `start_watcher.ps1` / `stop_watcher.ps1` の `$virtual` を直す。
